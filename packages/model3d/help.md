# 3D 课堂演示

一个完全离线的 3D 教具：在讲台上当堂搭立体、把几个块粘成一体、把一个长方体展开成平面展开图，
再设好质量、重力、弹性、摩擦、初速，点一下就开始物理模拟。

左上角「新建」造物体 → 中间拖动摆位置 → 右侧设物理量 → 点「启用模拟」。

## 怎么用

**搭**：长方体 / 正方体 / 球 / 圆柱 / 圆锥 / 三棱柱，点一下就落到地面上，颜色自动错开。

**摆**：场景里左键按住物体可在地面上拖（拖动时不跑物理）；拖空白处转视角，滚轮远近，右键平移。
也可以直接拉左侧的位置 X / 高度 Y / 位置 Z 滑杆，或用方向键微调、Q/E 转 15°、Delete 删除。

**粘合**：按住 Shift 点选两个及以上物体 → 「粘合成组」。粘合后它们作为一个刚体一起受力，
质量取成员之和，弹性/摩擦取平均。选中组点「拆开」还原成独立物体。

**展开**：选中长方体 → 「展开为平面图」，六个面会飞到地面摊开，并自动把视角抬高到俯视；
「折叠回立体」原路收回去。六个面各自带一点深浅差和黑色棱线，方便在投影上逐个指认；
展开总面积恒等于表面积（可以做「表面积 = 展开图面积」的验证）。
展开期间那个立体本身已经藏起来，不会再被点中或拖走（以前拖了它再折叠会「飞回老地方」，
现在折叠按物体当前的位置收回去）；展开着的物体会暂停参与物理，想跑模拟先折回去。
注意：只有单个长方体/正方体可展开，粘合组不能展开。

**视图**：选中一个物体，按现在的观察角度把它「压」成一块平面轮廓：
- 「当前视角生成视图」：按你此刻看它的方向投影，画在画面左上方；
- 「正视（沿 Z 看）/ 俯视（沿 Y 看）/ 侧视（沿 X 看）」：从三个标准方向投影；
- 「绕 X 转 ±15° / 绕 Z 转 ±15°」：把投影方向转一点，轮廓跟着变，用来看不同角度下形状怎么变；
- 「清除视图」：把视图收掉。

长方体做「正视 = 宽×高、俯视 = 宽×深、侧视 = 深×高」的对照，正好配合三视图这节课。
同一物体再次生成会替换掉旧视图；视图只是看的，不参与物理。

**物理量（都有默认值，不填也能跑）**
| 量 | 默认 | 作用 |
| --- | --- | --- |
| 质量 m | 1.0 kg | 影响碰撞时谁被推得更远；面板实时显示 G = mg |
| 重力 g | 9.8 m/s² | 全局，可调到 0（失重）或 4.9（月球感） |
| 弹性 e | 0.40 | 落地反弹比例，1 完全不损失，0 不弹 |
| 摩擦 μ | 0.30 | 贴地时的水平减速 |
| 初速 vx / vz | 0 | 点「启用模拟」时给选中物体一个水平初速度 |

**模拟**：启用 / 暂停 / 重置（回到启用前的摆位）/ 清空。模拟中可随时改 g，看下落快慢变化。

## 四个课堂预设

- **自由落体**：一个立方体从 3.4 m 落下，落地反弹几次后停住。
- **两球对撞**：两球相向 2.6 m/s，看动量与反弹（等质量、e=0.75 时速度基本交换）。
- **三体堆叠**：方块 + 方块 + 球依次落下叠住，讲受力与支撑。
- **展开演示**：摆好一个 2.0×1.2×1.4 的长方体，点「展开为平面图」。

## 物理模型说明（讲原理时可直接说）

- 每帧切成 4 个子步，重力积分 + 位移积分。
- 落地：用包围盒最低点压回地面，法向速度按 e 反向，水平速度按 μ·g·t 做库仑式减速。
- 物体之间用**轴对齐包围盒（AABB）**求交，取重叠最小的轴分离，并按质量加权 + 弹性冲量交换速度。
  所以堆叠、挤压、对撞都成立，但**斜面、翻滚、非轴对齐的精确接触不支持**——本工具定位是课堂定性演示，
  不是仿真软件。
- 球在地面上滚动时按 v/r 转，看起来是滚而不是滑。

## 其他

- 「截图」把当前画面存成 PNG（默认下载目录），可以直接贴到课件里。
- 「复位视角」回到默认机位。
- 地址栏加 `?test=1` 会跑一遍内置自检（24 项：落地、对撞、粘合质量、展开面积、折叠还原、展开体不参与物理、
  折叠不瞬移、视图面积、改重力等），结果打印在画面左上角，用于排查「怎么不动了」这类问题。
